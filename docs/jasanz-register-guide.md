## 0. 事前に用意するもの

- インターネットに接続されたPC（入力欄が3列で並ぶため、画面の広いPCを推奨）
- Webブラウザ（Microsoft Edge または Google Chrome。STEP 2 の翻訳機能を使うため）
- 調べたい内容のメモ（会社名、証明書番号、国・都市名など。1つでも可）

> **ログイン不要** — 誰でも閲覧できる公開データベースです。アカウント登録は必要ありません。

## 1. 操作手順

### STEP 1 レジスターのサイトを開く

ブラウザを起動し、アドレスバーに次のURLを入力して **Enter** を押します。

```
https://register.jasanz.org/
```

URLを直接入力しない場合は、次のどちらでも同じサイトに到達できます。

- JASANZ公式サイト `https://www.jasanz.org/` を開き、ページ内の **JASANZ Register** のリンクをクリックする
- 検索エンジンで **JASANZ Register** と検索し、`register.jasanz.org` のリンクを選ぶ

**確認**：画面左上に青緑のモザイク模様の **JASANZ** ロゴが表示されていれば、正しいサイトです。

### STEP 2 画面を日本語表示にする（任意）

サイトは英語で表示されます。日本語で操作したい場合は、ブラウザの翻訳機能を使います。

- **Microsoft Edge** — アドレスバー右端の翻訳アイコン（`あ` / `文A`）をクリック → 翻訳先の言語を「日本語」にして「翻訳」を押す
- **Google Chrome** — ページの余白を右クリック →「日本語に翻訳」を選ぶ

> **注意** — 翻訳は機械翻訳のため、同じ英単語が場面によって別の日本語になることがあります（例：`Certifications` が「認定」、`Accredited Bodies` が「認定機関」と訳される）。判断に迷ったときは翻訳を解除して英語表記で確認してください。英語のまま使う場合、このSTEPは不要です。

### STEP 3 メニューから「認定（Certifications）」をクリック

ロゴの下に、横一列のメニュー（グローバルナビゲーション）があります。左から3番目の **認定（Certifications）** をクリックします。

| 日本語表示 | 英語表記（参考） | 内容 |
| --- | --- | --- |
| 重要なお知らせ | Important Notices | 運営からの告知・注意喚起 |
| 認定機関 | Accredited Bodies | JASANZの認定を受けた*認証機関そのもの*を探す |
| **認定 ←ここ** | **Certifications** | **発行された証明書を探す（今回の目的地）** |
| コードマークレジスタ | CodeMark Register | 建築製品向けCodeMark制度の登録情報 |
| 承認された制度 | Approved Schemes | 認証スキーム（制度）の一覧 |
| 概要 | About | レジスターの説明 |
| 連絡先 | Contact | 問い合わせ先 |

> **間違えやすい** — 「認定機関（Accredited Bodies）」は認証機関の一覧で、別の画面です。証明書を探すときは「認定（Certifications）」を選びます。

### STEP 4 「フィルター」画面が表示されたことを確認

次の4点がそろっていれば到達完了です。

- [ ] アドレスバーが `register.jasanz.org` のままになっている
- [ ] 紺色の帯（ヘッダー画像）の中に **認定 / Certifications** という大見出しがある
- [ ] その下に **フィルター / Filter** という見出しがある
- [ ] 入力欄が **証明書保持者・認証詳細・認証** の **3列** に分かれて並んでいる

### STEP 5 条件を入力して検索する

調べたい条件を入力し、緑色の **検索（Search）** ボタンを押します。条件をやり直すときは隣の **リセット（Reset）** で全項目が空になります。

- 最初は **組織名だけ** など1〜2項目で広めに検索し、件数が多ければ条件を足して絞り込む
- 各入力欄の右にある **ⓘ** アイコンにマウスを合わせると、その項目の説明が表示される
- 証明書の真偽を確かめたいときは、証明書に記載された **証明書ID** で検索するのが最も確実

## 3. 入力項目の一覧

すべて埋める必要はありません。

### グループ1 ─ 証明書保持者 / Certificate Holder（「誰の証明書か」から探す）

| 項目 | 英語表記（参考） | 入力するもの |
| --- | --- | --- |
| 証明書ID | Certificate ID | 証明書に記載された固有の番号。真偽確認にはこれが最短 |
| 組織名 | Organisation Name | 認証を受けた会社・団体の名称（英語の正式名称で入力） |
| 証明書保持者 | Certificate Holder | 証明書の名義。組織名と異なる場合に使用 |
| 郊外/都市 | Suburb / City | 所在地の都市名・地区名 |
| 国 | Country | 所在国。一覧から選択 |

### グループ2 ─ 認証詳細 / Certification Details（「誰が発行したか・どの業種か」から探す）

| 項目 | 英語表記（参考） | 入力するもの |
| --- | --- | --- |
| 認定機関 | Accredited Body | 証明書を発行した認証機関。一覧から選択 |
| 認証の種類 | Certification Type | マネジメントシステム／製品／要員 などの区分 |
| ISICコード | ISIC Code | 国連の国際標準産業分類コード（業種の分類） |

### グループ3 ─ 認証 / Certification（「何の規格か」から探す）

| 項目 | 英語表記（参考） | 入力するもの |
| --- | --- | --- |
| スキーム | Scheme | 認証制度の名称。一覧から選択 |
| 標準 | Standard | 規格。ISO 9001、ISO 14001 など。一覧から選択 |
| 認証の説明 | Certification Description | 認証範囲に含まれる語句をキーワードとして入力 |

※ 日本語の項目名はブラウザの機械翻訳による表示です。英語表記は参考であり、サイトの更新により文言が変わる場合があります。

## 4. うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| メニューが見当たらない | ページ最上部までスクロールする。ウィンドウを最大化すると横一列で表示される |
| 翻訳アイコンが出ない | ページを再読み込み（`F5`）する。Edgeの「設定 > 言語」で「自分が読めない言語のページの翻訳を求める」をオンにする |
| ページ移動で英語に戻る | 翻訳はページごとにかかるため、移動先で再度翻訳を実行する |
| 検索結果が0件 | リセットして項目を1つだけにする。会社名は英語の正式名称で登録されている点に注意。それでも出ない場合はJASANZ認定の範囲外か有効期限切れの可能性 |
| 探しているのが認証機関だった | メニューの「認定機関（Accredited Bodies）」に切り替える |
