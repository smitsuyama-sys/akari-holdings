# 焼肉すどう 系列サイト

| ファイル | 内容 |
|---|---|
| `index.html` | ブランドトップ（4店舗への入口・哲学・あゆみ） |
| `kumamoto.html` | 焼肉すどう 熊本本店 |
| `haruyoshi.html` | 焼肉すどう 春吉 |
| `yoko.html` | 焼肉ヨーコ（大濠） |
| `newyoko.html` | 焼肉ニューヨーコ（春吉） |
| `assets/site.css` / `assets/site.js` | 共通スタイル・演出 |
| `build.mjs` | 店舗データから各ページを生成するスクリプト（`node build.mjs`） |

文言・価格・営業時間を直すときは `build.mjs` 内の `stores` 配列を編集して `node build.mjs` を実行してください。
生成された HTML はコミット済みなので、Netlify 側のビルド設定変更は不要です。

## 掲載情報の出典と注意
食べログ、各店公式サイト、ホットペッパー、Retty、ぐるなび、一休、RKB・UMAGA の記事など公開情報をもとに作成。
媒体により差がある項目は次の通りです。公開前に各店へご確認ください。

- 熊本本店: 営業時間（公式 17:00–23:00 を採用。ホットペッパーには水〜土のランチ掲載あり）、創業年（2012 独立／2013 開店）
- 春吉: 営業時間（17:00–24:00 を採用。12:00 開店とする掲載あり）、定休日（不定休を採用。日曜定休とする古い掲載あり）、サービス料10%別
- ヨーコ: 席数（公式ブログの20席を採用。40席とする掲載あり）、定休日（不定休を採用）、電話番号が媒体で3種類
- ニューヨーコ: 営業時間（12:00–24:00 L.O.22:30 を採用。17:00 開店とする掲載あり）、昼焼肉の価格は目安
- Web予約リンク（TableCheck）は熊本本店以外は推定URLのため、各店の実際の予約ページに差し替えてください

## ロゴ・写真
- `assets/logo-ivory.png` / `assets/logo-gold.png`: 店舗ロゴ（提供画像から背景を透過処理）
- `assets/grill-master.jpg`: 焼師の写真。トップ・熊本本店・春吉のヒーロー背景と「焼師」セクションに使用

## 写真の入れ方
各ページの `<figure class="visual">` と `<figure class="space-visual">` の中に `<img src="..." alt="...">` を追加すると、既存の演出の上に写真が全面表示されます。
